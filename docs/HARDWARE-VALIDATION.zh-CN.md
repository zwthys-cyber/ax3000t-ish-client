# 2026-10-28 单台 RD03v2 实机验证记录

[返回首页](../README.md) · [机器可读验证状态](../ISH_VALIDATION.json)

本记录来自设备操作输出、远程只读诊断及用户反馈。仅记录技术结果；不收录完整终端转储、设备标识、校准区、节点凭据或截图原件。

## 已观察到的结果

1. 原厂识别 `RD03v2`，NAND `flash_type=0x11` / ESMT F50D1G41LB，通过 v2.0.2 的支持检查。
2. 手机 iSH 收到原厂 root 回连，成功备份 APPSBLENV、ART、bdata、APPSBL 和 U-Boot 环境，ART 与原设备匹配。
3. 向空闲 `rootfs_1` 写 RAM 安装镜像；UBI 回读 16,633,856 字节，对应镜像 MD5 一致。
4. 重启后手机连接 `OpenWrt-RD03v2-Installer`；SSH 检查板型正确、`rootfs_type=tmpfs`、ART 指纹匹配，永久镜像 NAND gate 通过。
5. 上传镜像校验与 `sysupgrade -T` 通过，记录 `flash-started` 后启动永久刷写。
6. 永久 Wi-Fi 可连接；首次认证失败后使用正确 root 密码，通过 `--verify-only`，确认板型正确、`rootfs_type=overlay` 和原设备 ART 匹配，安装器报告已装到 NAND。
7. WAN 网线接通，LAN 改为 `192.168.10.1/24` 避免与上游 `192.168.1.0/24` 重叠；软件源更新成功，LuCI 中文包安装完成。
8. 定制 dnsmasq-full 安装完成；LAN DHCP 配置保留，127.0.0.1 和 LAN 地址的 DNS 查询均得到 IPv4 / IPv6 结果。没有专门做真实 nftset 写入或 DHCPv6 完整功能回归。
9. OpenClash 0.48.002 安装；处理 ucode/Lua 与 RPC ABI 不一致后页面可用。
10. 原压缩 Meta 内核更新时发生 OOM；外部 UPX 解包后在设备版本检查成功。导入私人配置后 Meta 运行，控制面板有连接与流量。
11. DNS 全局覆盖修复后，同一个代理节点下三次 DNS 查询由约 5 秒超时变成 0.17～0.51 秒成功；gstatic 204 请求由 5.62 秒降至 0.54 秒；用户确认“明显变快”。
12. 临时远程诊断授权与密钥已撤销，临时隧道监听已关闭。
13. Wi-Fi 页面显示 2.4 GHz / 5 GHz 同名 SSID；iPhone 连接 5 GHz，信号约 -35 dBm，80 MHz 双流链路速率约 1080 / 1201 Mbit/s。链路速率不是互联网带宽。

## 验证范围仍有限

- 只在一台路由器和这次版本组合完成，未声称所有 RD03v2 芯片都成功。
- 初始只读预检、软件模拟测试、实机刷写是三种不同证据；历史软件测试没有因此变成全量实机测试。
- 没有系统验证 iOS 后台暂停、断电、所有任意阶段中断后的恢复。
- `revert.py` / `restore.py` 的 iSH 原厂恢复路径没有实机验证。
- 本次流量与时间对照不是长时间稳定性、峰值带宽或所有协议的性能排名。
- 目标站 curl HTTP 403 没有当作浏览器播放成功；速度改善另有用户实际反馈。
- 保留 SNAPSHOT 版本边界，未来软件源变化后须重新模拟与核对依赖。
