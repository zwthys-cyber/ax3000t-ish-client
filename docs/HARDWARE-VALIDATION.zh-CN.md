# 这次在路由器上实际完成了什么

[返回首页](../README.md) · [详细检查数据](../ISH_VALIDATION.json)

2026-10-28，使用 iPhone 给一台小米 AX3000T RD03v2 安装 OpenWrt v2.0.2，再安装 OpenClash。正式系统已写入路由器，手机可以连接和使用；解决 DNS 查询问题后，用户确认网页打开明显变快。

下面记录实际完成的步骤。英文和数字是工具日志里的检查结果，方便对照，不需要全都记住。设备密码、节点账号、硬件备份和完整操作截图没有公开。

## 已经完成的步骤

1. **确认型号和闪存支持。** 工具认出设备是 `RD03v2`，闪存芯片是 ESMT F50D1G41LB（`flash_type=0x11`），v2.0.2 支持检查通过。
2. **手机成功取得路由器管理员连接，并完成备份。** 保存了 APPSBLENV、ART、bdata、APPSBL 和 U-Boot 环境；确认 ART 硬件数据来自本机。
3. **先把临时系统写入空闲位置。** 使用的是 `rootfs_1`，写完后读回 16,633,856 字节，核对 MD5 与对应文件一致。
4. **临时系统成功启动。** 手机连上 `OpenWrt-RD03v2-Installer`，登录后确认型号、原设备数据和闪存支持都正确。`rootfs_type=tmpfs` 表明正在运行内存中的临时系统。
5. **正式固件检查通过并开始写入。** 上传后的文件完整，`sysupgrade -T` 检查通过；工具保存 `flash-started` 进度后启动正式刷写。
6. **确认正式系统已写入。** 最初因密码用错而登录失败，改用正确 root 密码后，`--verify-only` 检查通过。型号和原设备数据一致，`rootfs_type=overlay`，工具报告系统已安装到闪存。
7. **网线、管理地址和中文页面设置完成。** 插好外网网线，将小米 LAN 改为 `192.168.10.1/24`，避免与上一级的 `192.168.1.0/24` 冲突；之后可以下载软件并安装中文界面。
8. **dnsmasq-full 补丁安装完成。** 原有地址分配设置保留，分别向 `127.0.0.1` 和路由器 LAN 地址查询域名，都拿到 IPv4 / IPv6 地址。没有另外逐项测试 nftset 写入和全部 DHCPv6 功能。
9. **OpenClash 页面可打开。** 安装 v0.48.002 后，修复了 ucode、Lua 和 RPC 配套软件不匹配的问题。
10. **解决了程序安装时内存不够的问题。** 原压缩版 Meta 程序被系统因内存不足而结束；在另一台机器上用 UPX 解包后传入路由器，版本检查通过。加入自己的配置后，程序正常运行，控制面板能看到连接和流量。
11. **解决了网页打开慢的问题。** 修复 DNS 总设置覆盖后，在同一个节点下，三次查询由约 5 秒超时变成 0.17～0.51 秒成功；gstatic 204 请求由 5.62 秒降至 0.54 秒。用户确认“明显变快”。
12. **临时远程诊断连接已关闭。** 相关临时授权和密钥已撤销。
13. **手机正常连接 5 GHz Wi-Fi。** 两个频段使用相同名称，手机实际连到 5 GHz，信号约 -35 dBm；页面显示 80 MHz、双流，连接速率约 1080 / 1201 Mbit/s。这是手机与路由器之间的速率，不是外网测速。

## 这些结果说明到哪里？

这说明本文这台路由器和这套软件版本已经成功操作过，不能直接推断所有 RD03v2、所有闪存或以后更新的软件都一样适用。

还没有完整测试 iPhone 在每个步骤切后台后的恢复、路由器断电恢复，以及用 iSH 恢复原厂系统。软件里的模拟测试，也不能当成这些情况都在真机上试过。

网页速度的前后对照是这次网络中的结果，不是最高带宽、长期稳定性或所有协议的排名。命令行访问目标站得到的 HTTP 403 没有被当作视频播放成功；实际变快另有用户在手机上的反馈。

SNAPSHOT 的下载服务器内容会继续更新，以后安装前仍要重新检查软件版本和依赖是否配套。
