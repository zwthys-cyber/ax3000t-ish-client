# 教程里的这些词是什么意思？

[返回首页](../README.md) · [常见问题](FAQ.zh-CN.md)

看不懂英文缩写时，可以回来查这张表。具体操作仍按[刷机教程](GUIDE.zh-CN.md)的顺序执行。

| 词语 | 在这份教程里的意思 |
| --- | --- |
| iSH | iPhone 上运行命令的终端 App，手机刷机工具在这里运行 |
| 固件 / OpenWrt | 安装到路由器上的系统 |
| LuCI | OpenWrt 的网页管理页面，本次用 `192.168.10.1` 打开 |
| OpenClash | 在 OpenWrt 上安装的网络代理插件，需要自己的节点配置 |
| Mihomo / Meta 内核 | OpenClash 实际处理连接的程序，不是路由器系统的 Linux 内核 |
| root | 路由器的管理员账号；root 密码用于登录管理，不一定等于 Wi-Fi 密码 |
| SSH | 从手机或电脑登录路由器、运行命令的连接方式 |
| SSID | Wi-Fi 的名称，例如 `OpenWrt-AX3000T` |
| WAN / LAN | WAN 接上一级网络；LAN 给自己的手机、电脑等设备使用 |
| DNS | 把网站名称查成服务器地址；查询超时会让打开网页变慢 |
| RAM / 临时系统 | RAM 是运行内存。临时安装系统在内存里运行，用来完成后面的正式安装 |
| NAND / 闪存 | 路由器用来保存系统和设置的存储芯片 |
| ART | 设备的 Wi-Fi 等硬件校准数据，要保存本机备份，不能拿别人的替换 |
| `resume.json` | 刷机工具保存的进度文件，断线后继续安装时需要它 |
| SHA-256 / MD5 | 文件或数据的校验值，用来核对内容是否完整、一致。教程要求使用哪种就按哪种检查 |
| 软件依赖 | 程序运行还需要的其他软件；缺少或版本不合适会装不上、打不开 |
| ABI 不匹配 | 配套程序之间接口对不上，常见原因是新旧版本混装 |
| OOM / Out of memory | 内存不够，系统可能会强制结束程序 |
| Release / Assets | GitHub 的下载发布页 / 页面中的附件列表 |
| 分支 / main | 仓库代码的一个版本 / 本仓库默认使用的分支名称 |

`tmpfs`、`overlay` 和 UBI 是安装日志中的存储相关名称。新手主要看工具是否确认临时系统、正式系统和文件检查都正确，不需要根据这些名字自己拼刷写命令。
